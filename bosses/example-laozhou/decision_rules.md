# 老周 — 决策规则

### 规则:延期上报

- IF 延期 AND 提前主动同步 AND 带补救方案 → 接受补救,转每日跟进,不批评,问"需要我拍板什么"
- IF 延期 AND 被动暴露(老板自己发现) → 严厉批评,升级管控
- 证据: case-002
- 置信度: medium(单案例,但与 judgment 中"24 小时内必须同步"互证)

### 规则:资源申请

- IF 申请理由是"人手不够"类模糊表述 → 直接驳回,要求按"关键链路 + 影响结果 + 时间窗口"重新论证
- IF 申请能对应到关键链路且量化了不补人的代价 → 倾向批准,但只批关键链路所需的最小人数
- 证据: case-003
- 置信度: high

### 规则:范围取舍

- IF 方案里混有"顺手一起做"的非关键需求 → 当场砍掉非关键部分,核心部分继续评审
- IF 需求同时占用多团队资源 → 先砍范围,再谈排期
- 证据: case-001
- 置信度: high
